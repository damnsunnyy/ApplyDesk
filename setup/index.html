HOSTED SETUP GUIDE

Connect your
private workspace.

The app code is live, but authentication needs a Supabase project owned by you. The project URL and publishable key are safe for the front end; your database policy keeps each account’s rows private.

1. Create Supabase

Create a free project in the Supabase dashboard. Copy its project URL and publishable key from Project Settings → API Keys. Free projects can pause after one week of inactivity, so the database may need waking when you return. Current pricing.

2. Apply the schema

In the project’s SQL Editor, run the migration in this repository: supabase/migrations/202610170001_apply_desk.sql. It creates profiles, applications, and email events with row-level security for each signed-in account. You can also use the documented database migration workflow.

3. Connect the web app

Edit job-hunt/config.js in your repository and set SUPABASE_URL plus SUPABASE_PUBLISHABLE_KEY. Do not use a service-role key here. Push the update; GitHub Pages will redeploy. In Supabase Auth → URL Configuration, set the site URL to https://damnsunnyy.github.io/ApplyDesk/ and add that same URL to the redirect allow list.

4. Enable live job search

Create an Adzuna developer account and obtain an app ID and key. Install the Supabase CLI, log in, and link this folder to your project. Store the API credentials as function secrets and deploy the included Edge Function. The browser calls the function; its API key stays server-side. Adzuna’s official API guide documents registration and search endpoints. The browser helper can fill known fields on a listing's application site. Optional auto-submit is limited to hostnames you explicitly allow and forms with no unanswered required fields.

supabase login
supabase link --project-ref YOUR_PROJECT_REF
supabase secrets set ADZUNA_APP_ID=… ADZUNA_APP_KEY=…
supabase functions deploy find-jobs

5. Optional Gmail reply tracking

Create a Google Cloud web OAuth client, enable the Gmail API, and add https://damnsunnyy.github.io as an authorized JavaScript origin. Set that client ID in job-hunt/config.js. The app requests only gmail.readonly, reads message subjects/senders/snippets, and stores matching signals in the signed-in user’s database. Google requires OAuth consent configuration for access to user Gmail; follow its official Gmail JavaScript quickstart. For an OAuth app still in testing mode, add each friend as a test user; publishing to the public requires completing Google's consent and verification requirements. Keep any OAuth client secret out of the front end.

Automation boundaries

The optional browser helper can submit a complete form only after you enable auto-submit and allowlist that exact host. It stops when it finds unknown required fields or sensitive declarations, and it cannot attach a résumé. Job sites use different forms and may restrict automation; confirm each site's rules. Gmail reply checks currently run while Apply Desk is open. Always-on inbox sync requires a separately deployed OAuth token store and scheduled server job; this repository does not yet include that connected service. Each friend must connect their own accounts.
