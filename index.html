APPLY DESK / FIRST-TIME SETUP

Bring your own private workspace online.

Accounts and cross-device job tracking need a Supabase project. This repository includes the account flow and database rules, but the live project URL and public key have not been connected yet.

  1. Create a free Supabase project.
  2. Run the SQL migration in supabase/migrations/.
  3. Copy the project URL and publishable key into job-hunt/config.js.
  4. Set up the optional job search and Gmail connections from the guide.
Open setup guide ↗Back to portfolio

Only the publishable key belongs in this browser app. Never put a service role key, database password, or provider secret in the repository.
